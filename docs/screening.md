# 产品版数据与报告口径

当前入口为 `data/product/`。基金池由26个名称主题与基础基金池合并而成；优先人民币A类，归并LOF/QDII标记差异，排除场内独立ETF、REIT及封闭持有产品。主题属于名称提示，持仓行业占比待核验。

境内股票、股票指数、混合、长债、黄金、商品及海外分组分别计算；每只基金保留自己的真实净值日期，不补齐不存在的净值。少于100期的基金参与数据覆盖统计，达到门槛后才参加同类排名。每日检查市场最新日期、申购状态和因子有效性，网页列出预热、历史与最新日期缺口。

同类分数使用动量40%、均线趋势25%、下行波动20%、距近期高点15%，权重保持初始设定。名单最多5只，主要主题最多1只、主题大类最多2只，黄金与长债合计最多1只；因子排序和名称主题分散提供初始筛选，实际持仓相关性仍需核验。同类样本少于10只时展示比较范围提示。

每份日报仅使用报告日前的净值。每只基金按现金分红计算总收益指数；未识别的公司行动按失败记录。原始接口响应和目录按内容哈希留存；新抓取的净值记录带逐页来源引用，刷新不会删除旧响应。

周报使用已发布的历史观察名单，观察起点为推荐日当日或之后首条净值，终点为该基金自身1期或5期之后的净值；只纳入截止日前成熟样本。比较同起止日的同类开放候选，保持净值毛收益口径。费用、确认与到账流程需在交易评测中另行处理。重叠样本存在依赖。

公共数据源未提供逐条真实发布时间，历史回放存在信息发布时间与当前目录幸存者偏差。历史申购文本的渠道、限额、费用和当前可交易性仍需交易前核验。日报与周报用于分析及改进建议，交易账户接入需单独开发。

# 300只基金的每日筛选与每周RSI

## 数据

准备脚本：`scripts/prepare-screening.py`。当前批次固定为2026-01-01至2026-09-30。

来源：东方财富公开基金目录 `https://fund.eastmoney.com/js/fundcode_search.js` 及历史净值接口 `https://api.fund.eastmoney.com/f10/lsjz`。按基金、日期范围、实际20条分页拉取，原始响应保存在 `data/screening/source/<code>/`。四线程、有间隔、有重试；再次运行复用已成功页面。

目录里按股票型、股票指数、偏股混合、长债选取。排除纯交易所ETF、持有/定开/封闭等名称和后端份额；保留ETF联接及可在场外申购的候选名称。按去除份额后缀的名称去重，优先A份额。名称规则不是产品法律属性的完整核验。

每类按 `SHA256(DQR-2026-09-v1:code)` 排序取前75个符合条件的基金，未用收益高低选样本。要求8月31日有净值、9月之前至少100条观察、9月参考交易日完整。328只尝试中选300只；全部28条拒绝原因可查。当前目录及事后完整性筛选意味着非严格时点样本，不能隐去这个局限。

本批53,781条净值：9月6,300条，预热47,481条。每只预热100—160期；不会为成立较晚的基金编造缺失历史。日历来源：[上交所2026年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。9月21个参考交易日；这只是国内日净值核查参考，不冒充各基金的官方净值公布日历。

现金分红按接口文本解析并计入总收益指数。无法识别的拆分/折算等公司行动会拒绝，不静默忽略。没有OHLCV、持仓行业穿透、申购限额或费率的完整时点数据。

## 每日筛选

执行程序：`strategies/screening-current.json`；解释器：`runtime/dqr/operators.py`；筛选/评测/图表：`runtime/dqr/screening.py`。

输入保留每只基金自己的历史，不对300只基金的日期取全局交集，不向前或向后填净值。仅使用报告日之前的最新参考交易日；缺失该日或预热不足的基金不能进入推荐。`cs_rank` 分别在四个类别内调用真实vn.py实现，采用最小并列名次除以有效数；并列分数再按代码升序稳定排序。

当前得分：平滑风险调整动量40% + EMA趋势25% + 低下行波动20% + 距60期高点回撤15%。每一项都先转为同类排名百分位。技术RSI、60期动量、趋势拟合等是解释项，当前不直接计分。权重是初始工程配置，没有经过优化。

下行波动是 `std(min(日收益,0),20)`，不是只对负收益样本算标准差。距60期高点不是最大回撤。`ts_decay_linear` 保留上游权重方向，窗口最旧值权重最高（3、2、1）；不能误称对最新值加权最高。`risk_adjusted` 波动分母下限0.001，债券可能频繁触及下限；这可以成为周报建议的对象，但本轮不改。

评分同类包含有有效值的75只基金；推荐再过滤历史状态“开放申购”，所以入选基金可能是同类第8名，而非第1名。限定开放状态只是保守筛选口径，不将限购产品当成不可投资，也不宣称可实际成交。每日报告保留完整排除记录。

首次报告没有此前推荐名单，替换率0为初始化值。周末/休市无新净值时延续名单，不强行每天换基金。股票1、指数1、混合2、长债1是展示名额，未考虑用户风险偏好，不是资金分配。

## 模型与每周反馈

DSH在数值计算之后工作。模型不重算净值、不拍脑袋换基金、不操盘；它解释实际公式/值/名次之间的冲突并提出有条件的判断。每份报告独立会话，通过JSON pointer引用至少3个精确证据值。

每周提供当周名单变化与截至截止日已成熟的累计1/5期信号观察：从推荐日当日或之后首个参考交易日净值起算，往后1/5个参考交易日结束；结束净值必须在该周截止前已知。同类基准是该信号时点符合筛选状态的同类基金平均毛收益。无新数据的日报不重复产生信号。

这不是基金申赎回测，没有模拟费用、份额、确认或到账，不输出虚假的组合收益率。样本重叠且可能反复推荐同一基金，不是独立统计样本。月末评测可以看9月30日净值，9月30日晨间周报只能看到9月29日，两个结果故意不同。

周报的每条建议包含因子名、表达式、依据、取舍和后续验证办法，状态为未执行/未评测。候选运行数0。OpenEvolve的搜索和RD-Agent闭环不启动；筛选程序未被建议自动替换。

## 产物与验证

`data/screening/dataset.json` 指向内容寻址数据集；`latest.json` 指向报告目录。目录内有30份日报（HTML/Markdown/JSON/CSV）、30张四联图、5份周报、固定程序、实际调用轨迹、月度诊断和清单。

`verify-screening.py` 从原始分页核对净值和申购状态，独立复算所有30天×300只的20/60期收益、距高点、同类百分位及最终评分，并核查所有成熟反馈的时间与收益；输出 `calculation-proof.json`。`verify-month.mjs` 检查实际DSH持久会话、模型身份、工具调用顺序、上下文哈希和最终文本，输出 `model-proof.json`。合成测试额外覆盖未来数据扰动不改变历史输出、单基金缺失不影响其他基金、暂停申购剔除及周末无重复信号。

数据和报告未加入版本控制，原始来源和本地绝对路径保存在对应清单中。本批只构建9月历史回放，尚未接定时调度、实时刷新和个人账户。

## 日报阅读层（2026-10-23 修订）

正文按基金展示关键支撑、相对弱项、短长周期冲突和简短模型判断。收益、波动统一百分比保留两位小数；排名百分位用整数。原始JSON/CSV保留完整数值、公式与证据，不做附录。模型原文版本在raw-analyses中保留。

优势/弱项比较的是各因子未加权的同类排名，不直接比较不同权重的贡献大小；各因子都较强时写“相对弱项”，不强行判为坏因子。净值处于高点时的低并列名次只是排名机制，不会被写成回撤风险。中文字体缺失时图表生成明确报错，不静默输出缺字图。

## 每日真实更新的当前就绪度

已验证：公开净值下载、数据留存、300基金计算和报告链路。四类基金各抽查一只，接口均返回2026-10-22的最新净值（见data/screening/live-probe/check.json）。此检查没有更新9月数据集。

尚未实现：新筛选主流程的动态日期/增量合并、按基金记录净值首次可见时刻、迟报和数据不足时的降级策略、定时调度与运行锁、失败告警，以及模型凭证到期后的稳定续期或降级。prepare-screening.py日期固定且缓存仅按基金/页码组织，不能直接加定时器当作每日更新器。

下一步最小日更链路应固定基金池，按时间范围增量拉取（缓存键含范围），校验新鲜度/分红/去重，再按可见数据筛选；缺失基金明确排除或标为等待，不伪装已更新。调度负责重试和只发布一次。模型失败时保留程序结果并标明解读未生成。此轮只核实能力，没有启用自动化。
